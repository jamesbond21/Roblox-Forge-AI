SETUP GUIDE

One-time setup

  1. 1
    Open the plugin file

    In Studio, create a Script in ServerStorage, paste in plugin/ForgeBridge.rbxm.lua, select it, then choose Plugins → Save as Local Plugin. Delete the original ServerStorage copy after it appears in PluginDebugService.

  2. 2
    Enable HTTP requests

    In Studio, open Game Settings → Security and enable Allow HTTP Requests for your place.

  3. 3
    Connect the bridge

    Open the Forge Bridge toolbar widget and paste the local token from this page. The server must stay running while connected.

  4. 4
    Generate and send

    Return to the Command Center, generate files, then click Send to Studio. The plugin creates scripts in the mapped services.

Transfers stay on this computer at 127.0.0.1. Roblox Studio asks to enable HTTP because the plugin talks to your local Forge server.

OPTIONAL PROVIDER

Configure server-side AI

Forge reads OPENAI_API_KEY and OPENAI_MODEL from the server process environment. Restart the server after setting them. The key is never saved in or sent from the browser.

OPENAI_API_KEY=your-key-here\nOPENAI_MODEL=gpt-4.1-mini\nnpm start

Without a key, local procedural generators remain available.
